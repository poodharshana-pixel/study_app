- `courses-internal-dtd.xml`: internal DTD with three course records and optional `reg_no`.
- `employees.xml` + `employees.dtd`: external DTD example with three employee records.
- `employees.xsl`: transforms employee XML into an HTML table in browsers supporting client-side XSLT.
- `recipes.xml` + `recipes.xsl`: two recipe records and XSLT output.

A browser displaying XML does not necessarily mean it validated the DTD. Use a validator supporting DTD validation if the question asks for validation.
